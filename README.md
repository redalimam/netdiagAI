# netdiagAI

\# 🌐 NetDiagAI — Diagnostic Réseau Intelligent



> Surveillez votre infrastructure réseau et recevez des rapports IA en temps réel.



\*\*Live demo :\*\* https://netdiag-ai.vercel.app



\## Fonctionnalités

\- Scan réseau complet (DNS, HTTP, connectivité)

\- Diagnostic IA avec score de santé et recommandations

\- Alertes email automatiques en cas de problème

\- Surveillance continue toutes les 30 minutes

\- Dashboard moderne et intuitif



\## Stack technique

\- \*\*Frontend :\*\* Next.js 14, React, Tailwind CSS

\- \*\*Backend :\*\* Python, FastAPI, PostgreSQL

\- \*\*IA :\*\* Groq API (Llama 3.3 70B)

\- \*\*Déploiement :\*\* Vercel (frontend) + Railway (backend)

\- \*\*Emails :\*\* Resend API



```bash

\# Backend

cd backend \&\& pip install -r requirements.txt

uvicorn main:app --reload



\# Frontend  

cd frontend \&\& npm install

npm run dev

```
